# 🚀 HireGen AI

> AI-Powered Recruitment Platform for Resume Screening, ATS Scoring, AI Interviews, and Candidate Management.

# 📌 Overview

Hiring talented candidates is often time-consuming, repetitive, and prone to human bias. Recruiters spend hours manually reviewing resumes, calculating ATS compatibility, scheduling interviews, and tracking applicants.

**HireGen AI** automates this entire recruitment workflow using Artificial Intelligence.

The platform enables recruiters to:

- Parse resumes automatically
- Calculate ATS compatibility scores
- Match resumes with job descriptions
- Generate AI-powered interview questions
- Evaluate candidate answers
- Rank applicants intelligently
- Track recruitment progress from a modern dashboard

The objective is to reduce hiring time while improving recruitment quality through AI-driven decision making.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/HireGen-AI.git
```

---

## Move into project

```bash
cd HireGen-AI
```

---

## Install dependencies

```bash
pip install -r requirements.txt
```

---

## Configure MySQL

Create a MySQL database

```
hiregen_ai
```

Import

```
database.sql
```

Update database credentials inside

```
app.py
```

---

## Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
